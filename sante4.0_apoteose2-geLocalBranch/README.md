Second version of the Apoteose project which is a software dedicated to helping on the diagnosis of Osteoporosis. This current version is a Web Based software that runs locally using a SQLite3 database.

<br>


<br>

# Installation

## ⚠️ Requirements

Before starting, you'll need to have installed the following tools:

* \[Git\](https://git-scm.com)
* \[Python\](https://www.python.org/)

Besides that, you're going to need a code editor of your preference., such as \[VSCode\](https://code.visualstudio.com/).

</br>

## 🔨 Installing and Configuring
</br>

To install the program complete the following steps

```bash
# Go to the terminal and Clone this repository
$ git clone
```

```bash
# Access the Project Folder
$ cd C:/ProjectFolder

# Create the Virtual Env
$ python -m venv .venv

# Activate the virtual env (MacOS/Linux)
$ source .venv/bin/activate

# Activate the virtual env (Windows)
$ .venv/Scripts/activate

# Install the Requirements
$ pip install -r requirements.txt
```

</br>

## 🚩 Running the Project
</br>

```bash
## On the terminal with the virtual env active
$ python manage.py runserver
```
